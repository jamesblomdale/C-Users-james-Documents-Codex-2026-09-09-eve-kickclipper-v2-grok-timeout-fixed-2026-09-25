The pipeline

From a long stream to clips ready for review

Transcription and editing run locally. Configured AI providers analyse candidates, with optional video review.

›
01 / CAPTURE
Capture

streamlink pulls the live feed into rolling 30-second chunks — or vod.py grabs a finished VOD in one stable pass.

›
02 / TRANSCRIBE
Transcribe

faster-whisper turns every chunk into a word-level, timestamped transcript — free, local, no API calls.

›
03 / DETECT
Detect

Transcript search finds candidates. A bounded context review checks the event, payoff and weaknesses before final ranking. Optional video review adds visible evidence.

04 / CLIP
Clip

ffmpeg cuts the segment, tracks the streamer's face into a 9:16 crop, and burns in word-synced captions.
